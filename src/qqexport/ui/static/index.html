使用帮助

四步就能导出

  1. 扫描 QQ —— 点顶部「扫描 QQ」。程序会自动找到本机 QQ 的安装目录、版本和消息库， 并在左侧列出本机所有 QQ 账号。
  2. 获取口令 —— 选好账号后点「获取口令」。程序会先退出 QQ，再以调试方式重新启动它， 在它打开数据库的瞬间截获 16 字节口令，成功后会自动把 QQ 重新启动。 抓不到时也可以手动填写。
  3. 加载聊天记录 —— 点「加载聊天记录」。第一次要解密 3 GB 左右的数据库， 大约 1~2 分钟，界面中央会浮出进度卡片（可以最小化）。之后再用会直接复用缓存，很快。
  4. 导出 —— 点「导出」，选格式（HTML / TXT / CSV / JSON / Excel / PDF / Markdown）、 输出目录和导出范围，然后开始导出。

常见问题

Q：换了 QQ 号，读不出来怎么办？
在左侧账号选择器里切到新账号，点旁边的「获取密钥」重新识别一次即可。 每个账号的密钥是分开保存的，互不影响。
Q：提示「需要识别数据库密钥」/「密钥已失效」？
说明这个账号还没识别过密钥，或者 QQ 改过密码导致密钥变了。 点弹窗里的「识别密钥」就行 —— 程序会自动退出 QQ、重新启动并登录，抓完再恢复正常。
Q：识别密钥失败？
先确认 QQ 已经登录过至少一次（能自动登录）。如果还是失败，可能是安全软件拦截了调试方式启动的 QQ， 可以把程序加到杀毒软件白名单后重试。
Q：加载很慢 / 卡在 54% 不动？
第一次加载需要重建损坏的群消息表，进度条会在某一段停留比较久，这是正常的， 耐心等待即可（实测约 110 秒）。
Q：导出 PDF / Excel 很久没反应？
全量导出（几十万条以上）时 PDF 和 Excel 合订本会非常庞大。 建议先用「每个会话最多导出（条）」限制条数，或者改用 TXT / CSV / JSON 这类流式格式。
Q：提示「Windows 已保护你的电脑」？
这是 SmartScreen 对「没有数字签名的新程序」的常规提示，不是病毒。 点「更多信息」→「仍要运行」，或者右键文件 → 属性 → 勾选「解除锁定」即可。
Q：怎么卸载？
走安装向导装的话，在「设置 → 应用」里找到「QQ导出助手」卸载， 或者运行安装目录里的卸载入口。绿色版直接删掉 exe 和 runtime 文件夹即可。

界面说明

  • 顶部 步骤条：显示当前进行到第几步，点任意一步可直接跳到对应操作。
  • 顶部 「🔑 获取密钥」：最常用的按钮。没有密钥时点它就会自动识别。
  • 左侧 账号选择器：徽章颜色代表状态 —— 绿色「已就绪」、黄色「需要密钥」、红色「密钥失效」。
  • 左侧 搜索框：按会话名称或群号过滤。
  • 底部 状态栏：显示数据库路径、会话数与消息数。

隐私与数据安全

  • 仅在本机运行：解密、解析、导出全部在你的电脑上完成，程序不访问互联网， 也没有任何云端账号或服务器。
  • 聊天记录不上传：程序只读取本机 QQ 的消息库，不会把聊天记录、数据库密钥 或导出文件发送到任何地方。
  • 本地界面：界面由程序在本机 127.0.0.1 上临时开的一个端口提供，只用于把页面 显示在自己的窗口里，数据不会离开本机；并已校验 Host / Origin，其它网页无法读取。
  • 数据留在本机：解密缓存（运行目录下的 plain 文件夹）和导出文件都在你自己的 磁盘上，随时可以删除。
  • 无统计、无遥测：程序不收集使用数据，也不会自动联网检查更新。

高级

自动识别始终失败时（例如 QQ 版本特殊、被安全软件拦截）， 可以手动粘贴 16 字节数据库密钥。普通用户不需要用到。
